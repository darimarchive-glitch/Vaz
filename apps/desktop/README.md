# VAZ Desktop

Cliente planejado da rede VAZ. A interface deverá incluir Caixa de Entrada, Enviados, Rascunhos, Contatos, Dispositivos, Segurança e Rede.

O núcleo criptográfico permanece separado da UI. Chaves privadas não devem ser enviadas para serviços web. A primeira UI será conectada quando os formatos do core estiverem estáveis e houver testes de segurança mínimos.
